VOR Tracker — Version Maintenance
Tracks the latest released version of each tool in latest-versions.json. Tools warn their users to refresh if their build is behind the version recorded here.
Connecting…
"Live build" is read directly from each deployed page. "Released (tracked)" is the version recorded in latest-versions.json — the value that triggers the "update available" prompt in older builds. Use Mark as released once you're happy with a tool's current build; this is the only thing that writes to the tracker.
